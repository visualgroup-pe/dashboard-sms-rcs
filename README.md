# Dashboard SMS · RCS

Dashboard web de campañas SMS, SAT PUSH y RCS (Leads, CTA, PV, %Efect) publicado con GitHub Pages.

- `index.html`: la página (no requiere servidor; lee `data.json`).
- `data.json`: datos exportados desde `PROGRAMA SMS.xlsx` (HojaMadre-2026) y `PROGRAMA RCS.xlsx` (Conversaciones 2026), desde mayo 2026. Solo contiene columnas de medición (fecha, hora, tipo, base, producto, Q base, Leads, PV).

Para actualizar: doble clic en `Automatizacion-SMS\Publicar_Dashboard.bat`.
